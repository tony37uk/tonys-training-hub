Getting Started with AI Coding Tools

⏱️ 25–30 minutes 🟢 Beginner to intermediate 🛠️ Lovable · Replit · Copilot · Cline · Codex 🗓️ Updated November 2026

AI coding tools can now build whole apps from a description, fix bugs, write tests and explain unfamiliar code. This guide covers five of the best, each with a free way to start: what each one is for, how to set it up, and the habits that get good results without nasty surprises.

🎯

What you'll learn: Which tool suits which job, the golden rules that apply to all of them, and step-by-step setup and best practices for Lovable, Replit, GitHub Copilot, Cline and OpenAI Codex.

⭐ The golden rules (for every tool)

Whichever tool you pick, these habits make the biggest difference to the quality of what you get — and keep you out of trouble.

1

Always have a way back

Use version control (Git and GitHub) or the tool's own history, and save a checkpoint before any big change. Every tool here can undo — but only if you've kept a good version to go back to.

2

Plan first, then build

All five tools have a planning step. Use it for anything bigger than a small tweak: let the AI ask questions, review its plan, and only then let it write code. It's cheaper and far less likely to go off in the wrong direction.

3

Work in small steps

Ask for one feature at a time, check it works, then move on. Big "build me everything" requests are harder to review and harder to fix when something breaks.

❌ Too much at once

"Build a full helpdesk system with logins, tickets, email alerts, reports and an admin dashboard."

✅ One step at a time

"Create a simple form where staff can log a ticket with a title, description and priority, and show the tickets in a list. No logins yet."

4

Write down your project rules once

Each tool can read a standing set of instructions — your tech stack, coding style, what to avoid — so you don't repeat them in every prompt.

ToolWhere your rules go
LovableProject knowledge and workspace knowledge
ReplitContext you add to the Agent chat, plus your plan
GitHub Copilot.github/copilot-instructions.md or AGENTS.md
Cline.clinerules
OpenAI CodexAGENTS.md

AGENTS.md is an open standard read by several tools, so one file can serve more than one of them.

5

Review and test everything

AI-written code can look right and still be wrong or insecure. Read what changed, run it, click through it, and ask the AI to write tests. Treat it like a pull request from a keen new colleague.

6

Keep secrets out and approvals on

Never paste API keys or passwords into a prompt or into code — use the tool's Secrets feature or a .env file that's excluded from Git. Leave approval prompts switched on until you really trust the tool, and set a spending limit on any API key. See AI Security Basics for more.

💜 Lovable — build an app by describing it

Lovable turns a plain-English description into a working web app with a polished design, and can add a database, logins and payments. It's the friendliest starting point if you don't write code.

⚙

Setup

  1. Sign up free at lovable.dev.
  2. Describe your app in the prompt box — who it's for, what it should do, and how it should look.
  3. Switch to Plan mode for anything bigger than a tweak. Lovable asks questions and proposes a plan you can edit before any code is written.
  4. Approve the plan and let it build. Use Chat mode when you just want to talk through options.
  5. Add your standing rules and brand details in Knowledge.
  6. Connect GitHub if you want your own copy of the code, then Publish.
✓

Best practices

  • → Plan mode messages use credits too, so plan in a few well-thought-out messages rather than lots of tiny ones.
  • → Every change is saved in History, so you can revert to a working version if a change goes wrong — then re-prompt more clearly.
  • → When something breaks, try the built-in Try to fix button before writing a new prompt.
  • → Run a Deep scan in the Security view before you publish — it doesn't run automatically, and it doesn't replace a proper review for anything handling real user data.

🧡 Replit — build and learn in the browser

Replit combines an AI Agent with a full coding environment, hosting and a database, all in your browser. You can build by describing what you want, then open the code, edit it and learn how it works.

⚙

Setup

  1. Sign up free at replit.com.
  2. On the home screen, describe the app you want.
  3. Turn on the Plan toggle in the chat box before sending. The Agent breaks the work into a task list for you to review.
  4. Accept the tasks (or revise them) and the Agent starts building, showing a live preview.
  5. Add any API keys in the Secrets pane — never in the code.
  6. Publish when you're happy, to get a live web address.
✓

Best practices

  • → Replit saves checkpoints as the Agent works. If it goes wrong, open the Agent history and choose Rollback here.
  • → Give context the easy way: paste error messages, screenshots or sketches straight into the chat.
  • → Start a new Agent chat when you switch to a different task — it keeps things focused and uses fewer credits.
  • → Set a usage limit and budget in your account so you're never surprised by a bill. Replit asks before starting paid work.

🐙 GitHub Copilot — AI help inside VS Code

Copilot suggests code as you type, answers questions about your project in a chat panel, and has an agent that can make changes across files. It's built into VS Code and fits naturally with GitHub — including the site you set up in the GitHub Pages guide.

⚙

Setup

  1. Install or update Visual Studio Code and create a free GitHub account if you don't have one.
  2. Hover over the Copilot icon in the status bar at the bottom and select Use AI Features (or Set up Copilot).
  3. Sign in with GitHub. If you don't have a subscription, you're signed up for the free plan automatically.
  4. Open a project folder and start typing — grey suggestions appear; press Tab to accept.
  5. Open the chat panel to ask questions, or switch it to Agent to let Copilot make changes for you.
✓

Best practices

  • → Add a .github/copilot-instructions.md file describing your project and conventions — Copilot reads it automatically.
  • → Point Copilot at the right files: open the ones that matter, or reference them in your chat message.
  • → Review the agent's changes in the diff view before keeping them, and commit to Git often.
  • → Keep an eye on the usage indicator — the free plan has a monthly allowance, and plans and limits changed several times in 2026.

🤖 Cline — the open-source agent for VS Code

Cline is a free, open-source coding agent that lives in VS Code. You choose the AI model — Claude, GPT, Gemini, or a local model on your own machine — and it asks your permission before each change or command. That makes it an excellent tool for learning how coding agents work.

⚙

Setup

  1. In VS Code, open the Extensions panel, search for Cline and install it.
  2. Open Cline from the sidebar and choose a provider: add your own API key, use Cline's own provider, or connect a local model through Ollama or LM Studio.
  3. Open your project folder and describe the task.
  4. Start in Plan mode (toggle at the bottom of the panel). Cline explores your code and proposes an approach without changing anything.
  5. When the plan looks right, switch to Act. Cline proposes each change — click Approve to apply it.
✓

Best practices

  • → Use Checkpoints to undo a step that went wrong — they're your safety net.
  • → If approving gets tedious, turn on Auto-approve only for safe actions like reading files. Avoid YOLO mode, which approves everything, including risky commands.
  • → Put your project's standards in a .clinerules file so Cline follows them every time.
  • → You pay your model provider directly, with no monthly cap — so set a spending limit on your API key and watch the cost shown in Cline.

⌨️ OpenAI Codex — a full agent with your ChatGPT account

Codex is OpenAI's coding agent. It reads your project, makes changes, runs commands and tests, and can work in your terminal, your editor, the ChatGPT desktop app or the cloud. It's included with ChatGPT plans, including the free plan, with usage limits that vary by plan.

⚙

Setup (terminal)

# Install (needs Node.js), or use Homebrew on a Mac
npm i -g @openai/codex
brew install --cask codex

# Go to your project and start Codex
cd my-project
codex

On first run, choose Sign in with ChatGPT. Then type /init to create an AGENTS.md file describing your project. Prefer not to use the terminal? Codex is also available in the ChatGPT desktop app and as an extension for VS Code.

✓

Best practices

  • → Keep AGENTS.md short and specific: how to run, test and build the project, and the rules to follow. It shapes Codex's behaviour more than anything else.
  • → Use /permissions to control how much freedom Codex has. By default it works inside your project folder and asks before going further — keep it that way while you learn.
  • → Ask Codex to run the tests after each change, and read the summary of what it changed.
  • → Always run it inside a Git repository so every change can be reviewed and undone.
🗓️

Prices and limits change often. All five tools changed their plans during 2026. Check each tool's pricing page for the current free allowance before you rely on it.
