Getting Started with Hermes Agent

⏱️ 20–30 minutes 🟡 Intermediate 🖥️ Self-hosted on your machine or a server 🗓️ Updated November 2026

Hermes Agent is a free, open-source AI agent from Nous Research that lives on your computer or a server, remembers what it learns about you and your work, and gets better at repeated tasks over time. You can chat to it in a terminal, in its desktop app, or from the messaging apps you already use.

💡

In one sentence: Hermes is a personal AI agent that writes its own "skills" from experience — so the tenth time you ask it to do something, it does it better than the first.

⚕️ What is Hermes Agent?

Hermes Agent was released by Nous Research — the AI lab behind the open Hermes family of language models — in February 2026, under the MIT licence. Like OpenClaw, it's a persistent agent that can take real actions: run commands, browse the web, manage files, send messages and run scheduled jobs. Its big difference is a built-in learning loop.

Costs: the software is free and open source. You pay for the AI model you connect — either through your own API key, or a paid Nous Portal plan, which bundles model access with extra tools like web search, image generation and text-to-speech.

⬇️ Installation

1

Option 1 — Hermes Desktop (easiest)

On Windows or macOS, download the Hermes Desktop installer from hermes-agent.nousresearch.com and run it. It installs both the desktop app and the command-line tool.

2

Option 2 — Command line

# macOS, Linux and WSL2
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash

# Windows (PowerShell)
iex (irm https://hermes-agent.nousresearch.com/install.ps1)

# Then reload your shell (macOS / Linux)
source ~/.bashrc     # or: source ~/.zshrc

🚀 First run

3

Run the setup wizard

hermes setup            # asks how you want to power Hermes
hermes setup --portal   # or: sign in with Nous Portal in one step

The Nous Portal route uses one sign-in for a model plus web search, image generation, text-to-speech and a browser tool. If you'd rather use your own API key, choose your provider in the wizard.

4

Pick your model

hermes model    # choose or change provider and model at any time
5

Start chatting

hermes --tui    # the modern terminal interface (recommended)
hermes          # the classic command line
hermes -c       # carry on your last conversation

Check that it replies without errors, can use a tool when it needs to, and keeps track across several messages. Then close it and run hermes -c to make sure it picks up where you left off.

🛡️ Make it safe before you connect anything real

An agent that can run commands, read files and send messages is powerful — which is exactly why you should set it up carefully. Do these before connecting your email, accounts or chat apps.

6

Run commands in a sandbox

hermes config set terminal.backend docker   # run commands inside Docker
hermes config set terminal.backend ssh      # or on a separate server

With Docker, Hermes's commands run in an isolated container instead of directly on your computer. Cloud sandboxes like Modal and Daytona are also available, and hibernate when idle.

7

Turn on only the tools you need

hermes tools    # see and switch tools on or off

The setup wizard's "Blank Slate" option starts with most tools switched off, so you add only what you trust. Keep command approvals on, and read what Hermes wants to do before you say yes.

8

Keep secrets in the right place

API keys and bot tokens belong in ~/.hermes/.env, set with hermes config set — never pasted into chats or into config.yaml. Use a separate API key for Hermes with a spending limit, so a runaway task can't run up a big bill.

⚠️

Prompt injection applies here too. If Hermes reads emails or web pages and can also take actions, hidden instructions in that content could try to steer it. See the AI Security Basics guide for how this works and how to limit the risk.

💬 Connect a chat app

Once chatting in the terminal works, connect a messaging app so you can reach Hermes from your phone.

hermes gateway setup     # walks you through Telegram, Discord, Slack and others
hermes gateway status    # check it's running
💡

Start with Telegram — it's the quickest to set up. Make sure the gateway's allowlist includes only your own account. An incomplete setup can leave your bot open to anyone who finds it.

🧠 Skills and memory — how Hermes learns

9

Skills it writes itself

When Hermes finishes something complex, it can save the method as a skill — a short instruction file — and improve it the next time. Skills use the open agentskills.io format, so you can read them, edit them and share them. You can also install community skills from hubs, but review each one first: a skill is effectively code your agent will follow.

10

What it remembers

Hermes keeps two small notes files — one about your work and environment, one about you and your preferences — plus a searchable history of past sessions it can recall from. You can shape its personality and tone with a SOUL.md file. Everything is stored in ~/.hermes/ on the machine it runs on.

🛠️ Things to try

  • → "What can you do, and which tools do you have switched on?"
  • → "Every weekday at 8am, send me a briefing in Telegram with the top Microsoft 365 and Azure service updates."
  • → "Check my GitHub repos for open pull requests and summarise them." — then run it again next week and see how its skill improves.
  • → "Write a Python script that exports our Intune device list to CSV, test it in the sandbox, and save it as a skill."
  • → "Research the latest NCSC guidance on AI and save a one-page summary to a file."

CommandWhat it does

Something not working? Try these in order: hermes doctor, then hermes model, hermes setup and hermes gateway status.
